================================================================================
AUXILIARY-HEAD STUDY
Does making every S-TIM head participate improve detection?

Four arms, all on configs/default.json (18-dim input, N=15, 60 train seeds,
180 epochs, 50 evaluation seeds). The only difference between arms is which
auxiliary loss terms are active. Encoder, input width, optimiser and the
early-stopping rule are identical in all four.

  published  : value 0.10, trust-weight 0.25, action 0.20, modality 0.00
  control    : all four auxiliary loss weights 0
  mod_only   : modality 0.30, the other three 0
  full       : the published three plus modality 0.30

Note on the published configuration: it is NOT "all auxiliary heads off".
value / trust-weight / incentive-action have always been on. Only the modality
head was off, and it was off in every config in the repository.
